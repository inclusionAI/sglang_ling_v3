## 1. Model Introduction

Ling-3.0-flash is a hybrid-attention Mixture-of-Experts (MoE) language model from the BailingMoeV3 family. It interleaves Kimi Delta Attention (KDA) linear-attention layers with gated Multi-head Latent Attention (MLA) full-attention layers, on top of a fine-grained MoE feed-forward network. This keeps per-token inference cost close to a small model — **124B total parameters with only 5.1B active** — while retaining large-model capacity.

It is a hybrid-reasoning model with thinking enabled by default, and it supports structured tool calling. Native context length is 128K, extendable to 256K and 1M with YaRN.

### Configuration Tips

- `--trust-remote-code` is required for the `BailingMoeV3ForCausalLM` implementation.
- Tensor parallelism follows the GPU: `--tp 4` on 141 GB-class cards (H20-3e, H200) and Blackwell (B200); `--tp 8` on 80 GB cards (H100, H800).
- `--reasoning-parser ling3` and `--tool-call-parser ling3` enable Ling-3.0-specific reasoning and structured tool-call parsing.
- Thinking is enabled by default; the chain-of-thought is returned in `reasoning_content` (see §4.3). A per-request thinking switch is being finalized for the public release.
- `--speculative-algorithm NEXTN` enables the NEXTN speculative decoding path.
- Native context is 128K. The reference recipe sets `--context-length 262144` and applies YaRN with factor 2.0 to extend it to 256K.
- The 1M YaRN recipe, SGLang version, and verified performance results will be added after final-model validation.

## 4. Model Invocation

Launch Ling-3.0-flash (the reference command below uses `--tp 4`; use `--tp 8` on 80 GB cards such as H100 / H800):

```bash Command
sglang serve \
  --model-path inclusionAI/Ling-3.0-flash \
  --trust-remote-code \
  --tp 4 \
  --enable-cache-report \
  --log-level info \
  --enable-metrics \
  --mem-fraction-static 0.85 \
  --max-running-requests 64 \
  --chunked-prefill-size 8192 \
  --allow-auto-truncate \
  --enable-trace \
  --tool-call-parser ling3 \
  --reasoning-parser ling3 \
  --context-length 262144 \
  --max-mamba-cache-size 320 \
  --speculative-algorithm NEXTN \
  --json-model-override-args '{"rope_scaling":{"rope_type":"yarn","factor":2.0,"rope_theta":6000000,"partial_rotary_factor":0.5,"original_max_position_embeddings":131072}}' \
  --host 0.0.0.0 \
  --port 30000
```

### 4.3 Thinking Mode

Ling-3.0-flash is a hybrid-reasoning model and reasons by default. With `--reasoning-parser ling3`, the chain-of-thought is returned in `message.reasoning_content` and the final answer in `message.content`:

<Accordion title="Thinking-mode request">

```bash Command
curl -s http://localhost:30000/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "inclusionAI/Ling-3.0-flash",
    "messages": [{"role": "user", "content": "What is 15% of 240?"}]
  }'
```

</Accordion>

<Accordion title="Example Output">

```json
{
  "choices": [
    {
      "message": {
        "role": "assistant",
        "content": "\n\n**15% of 240 = 36**\n\n**Calculation:**\n240 × 0.15 = 36\n\n**Quick check:** 10% of 240 = 24, and 5% of 240 = 12. So 15% = 24 + 12 = **36** ✓\n\n",
        "reasoning_content": "\n<think>\nThe question asks to find 15% of 240.\n\n15% = 0.15 = 15/100\n\n240 × 15/100 = 36\n\nVerification: 10% of 240 = 24, 5% of 240 = 12, so 15% = 24 + 12 = 36. ✓\n",
        "tool_calls": null
      },
      "finish_reason": "stop"
    }
  ]
}
```

</Accordion>

<Note>
A per-request thinking switch (`chat_template_kwargs.enable_thinking`) is being finalized for the public release. On the current pre-release checkpoint the model reasons by default and this toggle has no effect; the disable-thinking recipe will be added after final-model validation.
</Note>
